# 一起做饭 WeeCook

一家人各自往同一个菜谱本里加菜、商量今晚做什么。

菜谱 App 大多是一个人用的收藏夹。一起做饭想解决的是另一件事：家里几个人共用一个菜谱本，谁想起一道菜就随手记进去，做饭前一起翻一翻，今天吃什么就不用再吵了。

## 特点

- **离线优先**。菜谱存在手机本地，没网、在地下车库、在菜市场都能翻。不需要注册账号就能开始用。
- **一家人共用一本**。同一本菜谱可以多人一起维护，各自加各自的菜。
- **食材是结构化的**。「五花肉」「三层肉」在 App 里是同一个东西，所以按食材找菜谱不会漏。菜谱只记录用了什么、用多少，不存一段随手打的文字。
- **为多设备同步留了位**。每张表都带更新时间与删除标记，后续同步不会丢改动。

## 现在做到哪了

早期开发中，只有一个能跑起来的骨架和首页占位页：Android 能装能打开，桌面上能跑起来调试，菜谱功能还在做。

上面写的是这个项目要做成什么样，不是现在已经有的功能。
