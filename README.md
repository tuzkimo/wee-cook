# 一起做饭 WeeCook

自己录的菜谱默认只有自己看得到，想给谁看就公开到社区。

菜谱 App 大多是一个人用的收藏夹。一起做饭想解决的是另一件事：谁想起一道菜就随手记进去，做饭前翻一翻，今天吃什么就不用再吵了。一个服务器就是一个社区，你公开的菜谱同一台服务器上的人都能翻到，可以收藏、可以关注你。

## 特点

- **离线优先**。菜谱存在手机本地，没网、在地下车库、在菜市场都能翻。不需要注册账号就能开始用。
- **一个服务器就是一个社区**。菜谱默认私有；公开之后同一台服务器上的登录用户都能翻到，可以收藏、可以关注作者。
- **食材是结构化的**。「五花肉」「三层肉」在 App 里是同一个东西，所以按食材找菜谱不会漏。菜谱只记录用了什么、用多少，不存一段随手打的文字。
- **想同步再开，不开一样用**。不登录时所有功能都在，也不会发任何网络请求；填上自己那台服务器的地址、登录一下，菜谱就能跨设备同步，也能公开给社区里的人看。

## 多设备同步与社区共享

**不开启也完全可用。** 不填服务器地址、不登录时，App 不会发任何网络请求，功能一个不少，菜谱就存在这台手机上。

想多设备同步、或把菜谱公开给社区里的人看，需要自己搭一台服务器（见 [自托管指南](docs/SELF-HOSTING.md)），然后在 App 里：

1. 打开「我的」→「多设备同步」→ 填服务器地址 → 保存。地址填**到端口为止**，比如 `http://192.168.1.10:8080`，**不要**在后面加 `/api/v1`。
2. 在同一个页面登录或注册。登录后，这台手机上原有的菜谱会归到你名下并同步上去；换新手机登录同一个账号，菜谱就都回来了。

一个服务器就是一个社区：**菜谱默认只有自己看得到**，想给别人看就在菜谱详情页勾上「公开到社区」；别人的公开菜谱在菜谱页的「社区」段落里，可以收藏，也可以关注某个人。

几个要知道的规矩：

- 列表顶部有四个筛选：**全部 · 我的 · 收藏 · 关注**；列表分「我的菜谱」和「社区」两段。
- **只有录的人能改、能删**自己的菜谱。别人的菜谱你看得到、能跟着做，但详情页里没有编辑和删除按钮。
- 收藏之后菜谱会落到本机，**不联网也能看**；作者取消公开，下次同步后它就从你这里消失。
- 大家连的是同一台服务器；账号和数据都在你自己那台服务器上，没有我们的服务器参与。

公开范围就到这台服务器为止：没有跨服务器发现，也没有「只分享给某几个人」。完整的限制清单见 [同步与社区开发者文档](docs/开发者-同步与社区.md)。

## 现在做到哪了

菜谱的录入、编辑、删除，按食材和标签筛选，多设备同步，公开与社区浏览、收藏、关注，都已经能用了。Android 安装包还没发布——现在想装到手机上，得自己从源码构建。

还没做的是评论、点赞、通知、粉丝数 / 关注者列表、社区搜索、公开菜谱的协作编辑，以及服务器上的图片回收。
