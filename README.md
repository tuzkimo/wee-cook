# 一起做饭 WeeCook

一家人各自往同一个菜谱本里加菜、商量今晚做什么。

菜谱 App 大多是一个人用的收藏夹。一起做饭想解决的是另一件事：家里几个人共用一个菜谱本，谁想起一道菜就随手记进去，做饭前一起翻一翻，今天吃什么就不用再吵了。

## 特点

- **离线优先**。菜谱存在手机本地，没网、在地下车库、在菜市场都能翻。不需要注册账号就能开始用。
- **一家人共用一本**。同一本菜谱可以多人一起维护，各自加各自的菜。
- **食材是结构化的**。「五花肉」「三层肉」在 App 里是同一个东西，所以按食材找菜谱不会漏。菜谱只记录用了什么、用多少，不存一段随手打的文字。
- **想同步再开，不开一样用**。不登录时所有功能都在，也不会发任何网络请求；填上自己那台服务器的地址、登录一下，菜谱就能跨设备同步、和家人共用一本。

## 多设备同步与家庭共享

**不开启也完全可用。** 不填服务器地址、不登录时，App 不会发任何网络请求，功能一个不少，菜谱就存在这台手机上。

想多设备同步、或和家人共用一本，需要自己搭一台服务器（见 [自托管指南](docs/SELF-HOSTING.md)），然后在 App 里：

1. 打开「我的」→「多设备同步」→ 填服务器地址 → 保存。地址填**到端口为止**，比如 `http://192.168.1.10:8080`，**不要**在后面加 `/api/v1`。
2. 在同一个页面登录或注册。登录后，这台手机上原有的菜谱会归到你名下并同步上去；换新手机登录同一个账号，菜谱就都回来了。
3. 建一个家庭：「我的」→「我的家庭」→ 新建，起个名字（比如「我家」）。
4. 拉家人进来：在家庭页点「邀请家人」，会得到一串 **6 位数字邀请码**，**24 小时内有效**。让家人在自己手机上打开「我的」→「我的家庭」→「用邀请码加入」，输入这 6 位数字。
5. 加入之后，家人立刻能看到你之前录的家庭菜谱，你也能看到他后来录的。

几个要知道的规矩：

- 菜谱分两种：**自己的菜谱**（只有自己的设备看得到）和**家庭菜谱**。菜谱列表顶部的「我的菜谱 / 家庭名」用来切换，新建的菜谱记在当前这本里。
- **只有录的人能改、能删**自己的菜谱。家人的菜谱你看得到、能跟着做，但详情页里没有编辑和删除按钮。
- 一家人连的是同一台服务器；账号和数据都在你自己那台服务器上，没有我们的服务器参与。

家庭建好之后暂时不能改名、不能解散、不能退出，菜谱也不能在「我的菜谱」和家庭之间搬来搬去。完整的限制清单见 [同步与团队开发者文档](docs/开发者-同步与团队.md)。

## 现在做到哪了

菜谱的录入、编辑、删除，按食材和标签筛选，多设备同步，家庭共用，都已经能用了。Android 安装包还没发布——现在想装到手机上，得自己从源码构建。

还没做的是团队管理（家庭改名、解散、退出、移除成员）和服务器上的图片回收。
